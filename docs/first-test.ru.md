# Первый тест на Windows

Это прототип. Сначала проверь режим без модели, затем Ollama. Создай отдельный тестовый мир: бот умеет короткие движения, повороты, спринт, прыжок, удар, использование предмета и ломание блока под прицелом. Он пока не умеет искать путь и ставить блоки.

## Установка

1. Установи Minecraft Java Edition **1.21.11** с [Fabric Loader](https://fabricmc.net/use/installer/).
2. Положи в папку `mods` файлы [Fabric API для 1.21.11](https://modrinth.com/mod/fabric-api/versions?g=1.21.11), [Carpet 1.4.194](https://modrinth.com/mod/carpet/version/1.4.194) и `craftmind-mod-0.1.0.jar`. Последний можно собрать из `mod/` командой `gradlew.bat build`; он появится в `mod/build/libs/`.
3. Установи Python 3.11 или новее. В терминале открой папку `agent` и запусти `py -m craftmind.cli --mode scripted`.

## Проверка в мире

1. Открой одиночный мир. Команда `/craftmind status` должна показать адрес `127.0.0.1:8765`.
2. Введи `/craftmind spawn`. Должен появиться игрок `Craftmind`.
3. Напиши в обычный чат `@Craftmind иди вперёд`. Бот должен двигаться около двух секунд, остановиться и ответить в чат.
4. Попробуй `@Craftmind прыгни`, `@Craftmind стоп` и `@Craftmind статус`.

После обновления `dev` пересобери JAR и замени старый файл в `mods`, затем перезапусти Minecraft. Останови старый Python-агент через Ctrl+C и запусти новый. Для появления бота используй команду `/craftmind spawn`, а не сообщение `@Craftmind spawn`. Дополнительные проверки: `@Craftmind поверни налево`, `@Craftmind пробеги вперёд` и `@Craftmind осмотрись`. В режиме Ollama модель составляет короткие фазы плана; агент проверяет мир после каждого действия и передаёт новое наблюдение модели, когда нужен следующий этап. Неподтверждённый отказ модели вызывает повторное планирование. Отправленные во время работы задачи попадают в очередь; `@Craftmind стоп` отменяет текущую задачу. Для сравнения скорости можно запустить агента с `--no-think`.

Если бот не появляется, проверь наличие Carpet и его команды `/player`. Если агент пишет ошибку соединения, убедись, что мир открыт и `/craftmind status` показывает адрес моста. Скриншот ошибки, `logs/latest.log` и вывод агента помогут нам исправить первый запуск.

## Проверка с локальной моделью

Установи [Ollama](https://ollama.com/download/windows), затем выполни `ollama pull qwen3:14b`. Останови scripted-агента и из папки `agent` запусти `py -3.14 -m craftmind.cli --mode ollama --model qwen3:14b`. Проверь по очереди: `@Craftmind пройди несколько блоков вперёд, потом поверни направо`, затем `@Craftmind пройди несколько блоков вперёд, потом поверни направо и сломай 1 блок под собой`. Для добычи бот должен посмотреть вниз, получить новое наблюдение и только затем ломать блок под прицелом. Если действие остановилось, сохрани текст ответа в игре и вывод Python-агента с `Model plan` и `Step`.
