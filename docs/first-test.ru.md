# Первый тест на Windows

Это прототип. Для проверки подойдёт отдельный суперплоский мир в творческом режиме. Бот умеет двигаться на заданное число блоков, поворачивать, бегать, прыгать, ломать и ставить блоки. В творческом режиме он может брать зарегистрированные блоки в панель быстрого доступа; в выживании использует только блоки из своего инвентаря. Поиск пути и крафт пока не реализованы.

## Установка

1. Установи Minecraft Java Edition **1.21.11** с [Fabric Loader](https://fabricmc.net/use/installer/).
2. Положи в папку `mods` файлы [Fabric API для 1.21.11](https://modrinth.com/mod/fabric-api/versions?g=1.21.11), [Carpet 1.4.194](https://modrinth.com/mod/carpet/version/1.4.194) и `craftmind-mod-0.1.0.jar`. Последний можно собрать из `mod/` командой `gradlew.bat build`; он появится в `mod/build/libs/`.
3. Установи Python 3.11 или новее. В терминале открой папку `agent` и запусти `py -m craftmind.cli --mode scripted`.

## Проверка в мире

1. Открой одиночный мир. Команда `/craftmind status` должна показать адрес `127.0.0.1:8765`.
2. Введи `/craftmind spawn`. Должен появиться игрок `Craftmind`.
3. Напиши в обычный чат `@Craftmind иди вперёд`. Бот должен двигаться около двух секунд, остановиться и ответить в чат.
4. Попробуй `@Craftmind прыгни`, `@Craftmind стоп` и `@Craftmind статус`.

После обновления `dev` пересобери JAR и замени старый файл в `mods`, затем перезапусти Minecraft. Останови старый Python-агент через Ctrl+C и запусти новый. Для появления бота используй команду `/craftmind spawn`, а не сообщение `@Craftmind spawn`. В режиме Ollama модель составляет короткие фазы плана; общий лимит теперь 128 действий на задачу. Его можно изменить через `--max-steps`. Агент хранит только последние 16 действий в контексте модели. Повторение поворотов вправо-влево останавливается раньше лимита. `@Craftmind стоп` отменяет текущую задачу, в том числе длинное движение.

Если бот не появляется, проверь наличие Carpet и его команды `/player`. Если агент пишет ошибку соединения, убедись, что мир открыт и `/craftmind status` показывает адрес моста. Скриншот ошибки, `logs/latest.log` и вывод агента помогут нам исправить первый запуск.

## Проверка с локальной моделью

Установи [Ollama](https://ollama.com/download/windows), затем выполни `ollama pull qwen3:14b`. Останови scripted-агента и из папки `agent` запусти `py -3.14 -m craftmind.cli --mode ollama --model qwen3:14b`. В суперплоском творческом мире на свободной площадке проверь: `@Craftmind поставь три железных блока в ряд перед собой`. Ожидаемый план — один `place_line` с `block_id=minecraft:iron_block` и `count=3`; три блока должны стоять на земле по одной линии, а взгляд бота после установки должен вернуться в прежнее положение. Для отдельной клетки модель может использовать `place_at` с целыми координатами `x/y/z`; мод сам выбирает видимую грань соседнего блока и наводит прицел. Если установка не удалась, сохрани ответ в игре и строки `Model plan` и `Step` из окна агента. При проверке следующего ряда перейди на свободную площадку: занятые клетки нельзя заполнить повторно.
