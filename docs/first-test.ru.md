# Первый тест на Windows

Это прототип. Сначала проверь режим без модели, затем Ollama. Создай отдельный тестовый мир: бот пока умеет только простые движения.

## Установка

1. Установи Minecraft Java Edition **1.21.11** с [Fabric Loader](https://fabricmc.net/use/installer/).
2. Положи в папку `mods` файлы [Fabric API для 1.21.11](https://modrinth.com/mod/fabric-api/versions?g=1.21.11), [Carpet 1.4.194](https://modrinth.com/mod/carpet/version/1.4.194) и `craftmind-mod-0.1.0.jar`. Последний можно собрать из `mod/` командой `gradlew.bat build`; он появится в `mod/build/libs/`.
3. Установи Python 3.11 или новее. В терминале открой папку `agent` и запусти `py -m craftmind.cli --mode scripted`.

## Проверка в мире

1. Открой одиночный мир. Команда `/craftmind status` должна показать адрес `127.0.0.1:8765`.
2. Введи `/craftmind spawn`. Должен появиться игрок `Craftmind`.
3. Напиши в обычный чат `@Craftmind иди вперёд`. Бот должен двигаться около двух секунд, остановиться и ответить в чат.
4. Попробуй `@Craftmind прыгни`, `@Craftmind стоп` и `@Craftmind статус`.

Если бот не появляется, проверь наличие Carpet и его команды `/player`. Если агент пишет ошибку соединения, убедись, что мир открыт и `/craftmind status` показывает адрес моста. Скриншот ошибки, `logs/latest.log` и вывод агента помогут нам исправить первый запуск.

## Проверка с локальной моделью

Установи [Ollama](https://ollama.com/download/windows), затем выполни `ollama pull qwen3:14b`. Останови scripted-агента и из папки `agent` запусти `py -3.14 -m craftmind.cli --mode ollama --model qwen3:14b`. Повтори простую команду в чате. Агент включает рассуждение модели и просит выбрать одно действие из ограниченного списка. Новые игровые действия, например бег и добычу, надо добавить в код отдельно.
