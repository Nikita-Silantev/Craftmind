# Craftmind — план

## Цель

Открытый проект, с которым пользователь Windows сможет установить мод, запустить локальную модель и отдавать ей команды в Minecraft Java Edition.

## Первая версия

- Одиночный мир. Один бот с именем и обычным скином Стива.
- Команды игрока в чате: `@имя <задача>`. Бот сообщает о результате или ошибке.
- Начальные действия: осмотреться, переместиться, собрать простые ресурсы. Автономное прохождение игры и несколько ботов — следующие этапы.
- Локальная модель через Ollama. Скриптовый режим для проверки без модели.

## Стек и границы

- Мод: Fabric, Java, Gradle. Версию Minecraft и JDK закрепить после проверки совместимости.
- Агент: Python 3.11+, отдельный процесс с циклом задач и краткой памятью в SQLite.
- Мод и агент общаются через локальный API. Изменения мира выполняются в игровом серверном потоке.
- MCP-сервер в процессе агента открывает игровые инструменты внешним клиентам. Прямое управление ботом также работает без MCP-клиента.
- Первый поддерживаемый выпуск — Windows; архитектура не должна зависеть от Windows.

## Этапы

1. Проверить способ создать управляемого игрока со скином Стива в одиночном мире; выбрать совместимые версии Minecraft, Fabric и зависимостей.
2. Собрать минимальный мод: появление бота, чтение состояния мира, приём команды из чата.
3. Добавить агентный процесс, Ollama, простые инструменты движения и сбора ресурсов; проверить полный путь от команды до результата.
4. Добавить короткую память, обработку ошибок и скриптовый режим.
5. Подготовить сборку для Windows, инструкции установки, README на русском и английском и первый релиз.

## Критерий готовности первой версии

Пользователь по инструкции устанавливает Craftmind, запускает локальную модель, вводит в одиночном мире команду `@имя собери дерево` и видит, как бот выполняет её или понятно объясняет причину неудачи.
