# Craftmind

Craftmind — ранний прототип локального ИИ-компаньона для Minecraft Java Edition. Цель проекта: бот с именем и скином Стива, который выполняет команды игрока в чате одиночного мира.

Разработка идёт в ветке `dev`. Доступен первый прототип: бот появляется через Fabric Carpet и выполняет простые команды из чата. Добыча ресурсов и автономное поведение пока не реализованы. Дорожная карта — в [plan.md](plan.md).

## Сборка прототипа

Нужен JDK 21 или новее. В папке `mod/` выполните `./gradlew build` на macOS/Linux или `gradlew.bat build` на Windows. Мод рассчитан на Minecraft 1.21.11, Fabric API и Carpet 1.4.194. JAR появится в `mod/build/libs/`.
