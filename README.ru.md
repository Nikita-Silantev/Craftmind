# Craftmind

Craftmind — ранний прототип локального ИИ-компаньона для Minecraft Java Edition. Цель проекта: бот с именем и скином Стива, который выполняет команды игрока в чате одиночного мира.

Разработка идёт в ветке `dev`. Первый этап — Fabric-мод с командой `/craftmind status`; бот пока не появляется и не выполняет задания. Дорожная карта — в [plan.md](plan.md).

## Сборка прототипа

Нужен JDK 21 или новее. В папке `mod/` выполните `./gradlew build` на macOS/Linux или `gradlew.bat build` на Windows. Мод рассчитан на Minecraft 1.21.11 и Fabric API. JAR появится в `mod/build/libs/`.

## Текущий результат

Команда `/craftmind status` подтверждает загрузку мода. Это проверка для разработки, а не готовый игровой агент.
