# Craftmind

Craftmind — ранний прототип локального ИИ-компаньона для Minecraft Java Edition. Цель проекта: бот с именем и скином Стива, который выполняет команды игрока в чате одиночного мира.

Разработка идёт в ветке `dev`. Бот появляется через Fabric Carpet, получает команды из чата и перед каждым действием читает компактное состояние мира: положение, здоровье, голод, инвентарь, блок под прицелом и объекты поблизости. Агент может выполнить несколько шагов на одну задачу. Установка блоков, крафт и поиск пути ещё не реализованы, поэтому постройку дома он должен отклонять с объяснением. Дорожная карта — в [plan.md](plan.md).

## Сборка прототипа

Нужен JDK 21 или новее. В папке `mod/` выполните `./gradlew build` на macOS/Linux или `gradlew.bat build` на Windows. Мод рассчитан на Minecraft 1.21.11, Fabric API и Carpet 1.4.194. JAR появится в `mod/build/libs/`.
